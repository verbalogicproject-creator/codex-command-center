Level four · Human authority

Capability is not permission.

Every meaningful control is classified. Voice uses semantic actions, never coordinates or synthetic clicks, and it cannot cross protected product boundaries.

FAIL CLOSED · DEGRADE VISIBLY
Voice supported

Navigate and inspect

Open surfaces, run recall, focus graph nodes, inspect packets, manage tours, and edit reversible drafts.

Exact phrase

Publish a handoff

Only the exact phrase “Approve this handoff.” can publish the visible prepared draft.

Human tap only

Confirm durable memory

Models draft proposals. The authenticated human confirmation endpoint owns durable mutation.

Browser permission

Upload a screenshot

Voice cannot open the file chooser. Pixels are analyzed in memory and discarded.

Forbidden

Edit, install, or deploy

Aria cannot modify code, install tools, deploy services, reveal secrets, or invent capability references.

Never retained

Raw audio and credentials

Only bounded transcripts and receipts persist. WebRTC payloads, audio, SDP, and provider keys do not.
